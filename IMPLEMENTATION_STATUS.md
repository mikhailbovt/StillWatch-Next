- R08. Схема 16 сохраняет один краткоживущий receipt на устройство с AES-256-GCM. Windows защищает ключ Core через DPAPI, Ubuntu хранит ключ в файле только для владельца вне SQLite и его snapshot. Другой nonce с действующим retired credential отзывает устройство. В нативном LAN тесте ответ потерян после commit, Core перезапущен, два конкурентных повтора получают одинаковую пару, alert feed доступен, другой proof отзывает доступ. - C01. Companion сохраняет ограниченный индекс показанных уведомлений со стабильными ключами device/core/generation/incident/cycle. Home и потеря сети приостанавливают foreground polling. При изменении revision либо cycle приложение открывает актуальную карточку и сообщает об отмене ACK.
